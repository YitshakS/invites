# invites

אתר הזמנות לאירועים. כל אירוע = תיקייה ב-`events/<מזהה>/` + גיליון גוגל + פרויקט Apps Script משלו.

## כתובות

- אורח: `.../events/<מזהה>/?id=<מזהה אורח>`
- ניהול: `.../admin.html?e=<מזהה>`

## מבנה

- `invite.js`, `common.js`, `style.css`, `admin.html`: קוד משותף לכל האירועים.
- `events/<מזהה>/config.js`: כתובת ה-API, ערכת עיצוב (צבעים, רקע, קישוטים, מפה), ותצוגת הקישור בוואטסאפ (`share`).
- `events/<מזהה>/img/`: התמונות של האירוע.
- `events/<מזהה>/index.html` ו-`index.html`: דפי עטיפה שנוצרים אוטומטית. אין לערוך אותם ידנית.
- `tools/build-event.mjs`: יוצר את דפי העטיפה. וואטסאפ קורא כותרת ותמונה מקוד ה-HTML בלבד, ולכן לכל אירוע יש דף עטיפה משלו.
- `server/Code.gs`: קוד ה-Apps Script. מועתק לכל אירוע.

## אירוע חדש

1. בגיליון חדש: תוספים, Apps Script, להדביק את `server/Code.gs`, להריץ `setup` ולאשר הרשאות. הסיסמה מופיעה ביומן הביצוע (`ADMIN_TOKEN`).
2. פריסה: Deploy, New deployment, Web app, Execute as: Me, Access: Anyone. להעתיק את כתובת ה-`/exec`.
3. להעתיק תיקייה קיימת מ-`events/`, להחליף את `API_URL`, הכותרת, העיצוב ו-`share`. תמונת התצוגה: 1200 על 630.
4. `node tools/build-event.mjs` ליצירת דף העטיפה, ואז commit ו-push.
5. בדף הניהול, בלשונית "נוסחים": לערוך את נוסח הדף ונוסח הוואטסאפ.

עדכון קוד השרת: להדביק ב-Apps Script, ואז Deploy, Manage deployments, עריכה, New version. כך הכתובת לא משתנה ולא נצברות פריסות.

## נוסחים

מילים שמורות: `{שם בהזמנה}` `{שם פרטי}` `{שם משפחה}` (לפי העמודה בגיליון; אם "שם בהזמנה" ריק, מוצג השם הפרטי), ובוואטסאפ גם `{קישור}`.
מילה בארבע צורות לפי נוסח הפניה (יחיד, יחידה, רבים, רבות): `{היקר|היקרה|היקרים|היקרות}`.
`*טקסט*` מדגיש. `[טקסט](כתובת)` קישור, בדף בלבד. `{שם-קובץ.jpg}` תמונה מתיקיית `img` של האירוע, בדף בלבד (מזוהה לפי הסיומת: jpg, jpeg, png, webp, gif). `**טקסט**` כותרת גדולה, בדף בלבד, בכל מקום. שורה ריקה היא פסקה חדשה.

## תצוגת הקישור בוואטסאפ: עדכון אוטומטי

הכותרת והתיאור נערכים בלשונית "נוסחים" בדף הניהול ונשמרים בגיליון (לשונית "הגדרות", תאים B5 ו-B6). התמונה נשארת ב-`config.js` (`share.image`).
אחרי שמירה, הסקריפט מפעיל ב-GitHub את `.github/workflows/pages.yml`, שקורא את הגיליון, בונה מחדש את דפי העטיפה ומפרסם. התצוגה החדשה מופיעה אחרי כדקה. הודעות שכבר נשלחו לא יתעדכנו.

הגדרה חד־פעמית:

1. ב-GitHub: Settings, Pages, Source = GitHub Actions.
2. ב-GitHub: Settings, Developer settings, Personal access tokens, Fine-grained token. ריפו אחד (`invites`), הרשאה Actions: Read and write.
3. ב-Apps Script של האירוע: Project Settings, Script Properties. להוסיף `GITHUB_TOKEN` (הטוקן) ו-`GITHUB_REPO` (`YitshakS/invites`).
4. להריץ פונקציה כלשהי מהעורך ולאשר את ההרשאה לשליחת בקשות חיצוניות, ואז Deploy, Manage deployments, עריכה, New version.

בלי הטוקן השמירה עובדת, והעדכון באתר יתבצע בבנייה הבאה (כל push).
